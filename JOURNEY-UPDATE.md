# Regional landmarks and camera — 2026-10-14

Implemented:
- Jeddah: lower-density heritage buildings with projecting roshan screens, shop arches, stepped parapets, rooftop rooms; waterfront mosque silhouette with dome, colonnade and minaret; a curved modern tower.
- Red Sea: reflective curved overwater villas, glazed openings, pools, supporting piles and connected boardwalks.
- NEOM: mirrored exterior with recessed inner facades, varied terraces, planted floors, suspended garden bridges, vertical gardens and an open atrium canopy. This is an artistic interpretation, not an as-built representation.
- Qiddiya: a continuous terrain escarpment, a three-sided venue, varied pavilions and the existing entertainment structures. The terrain is one surface, avoiding overlapping-ground flicker.
- Camera: reversible authored lateral gaze, restrained lateral drift and upward looks at NEOM terraces; portrait framing adjusted; additional gestures disabled with reduced motion.

Verification:
- Desktop visual checks at Jeddah, Red Sea, NEOM interior and Qiddiya; mobile at NEOM and Red Sea.
- Full-quality autoplay sample near the NEOM entrance: 120 frames, 95th percentile frame interval 16.9 ms, quality scale 1. This is a local browser measurement, not a guarantee for all devices.
- Geometry is merged by material; foliage uses lower polygon meshes; existing adaptive resolution and idle rendering remain enabled.
- Existing build, catalog, audit and PDF verification scripts passed.
- Remaining visual scope: these are bespoke real-time architectural interpretations, not scanned photorealistic replicas. The route is a narrative composition, not a real rail itinerary.
